📊 Markdown Table Generator

Convert CSV, TSV or pasted spreadsheet data into a clean Markdown table. Choose alignment and copy the output instantly.

Why generate Markdown tables?

Markdown tables are the standard way to present structured data in README files, documentation, GitHub issues, Notion pages and static site generators. Hand-writing the pipe characters and separator rows is tedious and error-prone, especially for wide tables — pasting your spreadsheet export and converting automatically guarantees consistent alignment. The generator escapes pipe characters inside cells so your table never breaks, and works entirely offline in your browser.
